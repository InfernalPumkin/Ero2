WaterFall:

Modèle:
Étudiants → File 1 (K serveurs) → File 2 (1 serveur) → Retour

Modélisation théorique:
- File 1 : M/M/K (arrivées Poisson, temps de service exponentiel, K serveurs)
- File 2 : M/M/1 (mêmes hypothèses, 1 serveur)

Paramètres à définir :
λ = taux d’arrivée moyen (tags par heure)
μ₁ = taux de service de la file 1 (tests par heure)
μ₂ = taux de service de la file 2 (retours par heure)
K = nombre de serveurs (moulinettes) dans la file 1

pip install simpy numpy matplotlib pandas

1. Étudiant arrive → création d'un Job
2. Vérifie si la file 1 est pleine (ks)
   → Si oui : REFUSÉ (blocked_submit)
   → Si non : continue
3. Attend un serveur dans la file 1
4. Service dans la file 1 (temps exponentiel)
5. Vérifie si la file 2 est pleine (kf)
   → Si non : entre dans la file 2
   → Si oui :
        - Backup systématique : va dans backup_storage
        - Backup probabiliste : chance sur 2 d'aller en backup
        - Pas de backup : PERDU (dropped)
6. Si en backup : attend que backup_dispatcher le remette en file 2
7. Attend dans la file 2
8. Service dans la file 2 (envoi du résultat)
9. FIN : temps total calculé
